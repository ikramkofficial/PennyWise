# PennyWise - Expense Tracker

PennyWise is a simple open-source personal expense tracker built with HTML, CSS, and JavaScript. It helps users manage daily expenses, monthly budgets, reports, and savings insights directly in the browser.

The project is designed with a clean responsive interface, dark mode support, multilingual UI, currency options, expense graphs, and local browser storage.

## Features

- Add, view, and delete expenses
- Set monthly budgets by category
- View budget progress for the current month
- Generate monthly expense reports
- Download monthly reports
- Expense graph using Chart.js
- English and Urdu language support
- Multiple currency options
- Dark mode and light mode
- Login and signup system using browser local storage
- Disclaimer modal for users
- Responsive UI for desktop and mobile
- Simple HTML, CSS, and JavaScript structure

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Tailwind CSS CDN
- Chart.js
- Browser Local Storage
